NeuralMeter includes a bounded adaptation of the Antigravity model-selection
text parser from Token Meter, used only to derive allowlisted public model IDs
from explicitly consented local transcript content. No Token Meter runtime,
filesystem discovery, pricing, session database, tool, deletion, or UI code is
included.
